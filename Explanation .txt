Practical 3: A* Search for the 8-Puzzle Problem

Informed Search

1. Aim and concept

The 8-puzzle consists of eight numbered tiles and one blank space arranged in a 3 × 3 board. The objective is to rearrange the tiles into a target configuration.

A* uses this formula:

f(n)=g(n)+h(n)

: actual number of moves taken so far.
: estimated number of moves remaining.
: estimated total cost of the solution through that state.

    distance = 0

for i, tile in enumerate(state):

if tile != 0:

distance += abs(i // 3 - j // 3)

distance += abs(i % 3 - j % 3)

Calculates the tile’s Manhattan distance: vertical distance plus horizontal distance.

// 3 calculates a row number.
% 3 calculates a column number.
abs() gives a non-negative difference.
return distance

Defines a function that checks whether a queen can be placed at a particular row and column.

return False

return True

    return True

3. Understand the backtracking process

Step 1 — Choose

Place a queen in a safe column in the current row.

Step 2 — Recurse

Move to the next row and try placing another queen.

Step 3 — Check

If a later row has no safe position, return to the previous row.

Step 4 — Backtrack

Remove the previous queen and try another column until a solution is found.

Concept
